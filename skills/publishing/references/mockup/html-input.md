# 입력: HTML 목업

- 화면·상태의 기준 URL 또는 파일과 뷰포트·테마·데이터 조건을 확인한다.
- 프로젝트에서 계산값 스펙을 제공하면 원본과 조건이 일치하는지 확인해서 사용한다. 필요한 값이 빠졌으면 브라우저에서 목업을 실행하고 실제 표시 요소와 계산값을 확인한다.
- CSS 선언 순서·상속·변수·동적 스크립트가 적용된 결과를 비교한다. 화면 캡처 도구가 가린 요소와 목업에서 실제로 숨긴 요소를 구분한다.
- 오버레이·토스트·전환은 실행 가능한 목업 또는 명세로 확인한다. Figma 시안을 CSS로 적용한 HTML은 그 CSS가 적용된 화면을 캡처 조건에 기록한다.
- 이 저장소의 [계산값 도구](../../../../tools/mockup-spec/README.md)는 대상 목업과 설정이 맞을 때 사용한다.
