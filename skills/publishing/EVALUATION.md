# 퍼블리싱 스킬 점검

| 영역 | 현재 제공 기능 | 남은 적용 범위 |
|---|---|---|
| 스킬 | HTML/Figma와 앱/웹 분기, 항목별 기준 판정, 사용자 동작 확인 | 대상 프로젝트의 화면·테마·동작 정책 |
| HTML | 정적 목업의 브라우저 계산값 읽기와 Markdown 출력 | SPA·API 연동 상태의 캡처 |
| Figma | 프레임·상태·변수 모드·버전 확인 절차 | 노드에서 공통 수치 파일을 자동 생성하는 도구 |
| 검증 | PNG·수치 JSON 비교, 실패 코드, 차이 이미지, 자체 검사 | 각 앱의 화면·상태 자동 캡처 및 OS별 동작 테스트 |

## 사용 흐름

1. [스킬](SKILL.md)에서 입력·플랫폼을 선택한다.
2. 화면·상태·테마·뷰포트와 승인된 기준을 기록한다.
3. HTML은 [목업 추출기](../../tools/mockup-spec/README.md) 또는 브라우저를 사용한다. Figma는 지정 프레임과 버전을 확인한다.
4. 구현 화면에서 동일 조건의 PNG와 필요한 실측값을 얻고 [검증 도구](../../tools/publishing-verify/README.md)로 대조한다.
5. 구조·키보드·탐색·반응형 전환은 [검증 체크리스트](references/common/checklist.md)에 따라 실제로 실행하고 결과를 기록한다.
