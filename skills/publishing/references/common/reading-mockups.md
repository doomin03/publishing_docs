# 화면과 상태 읽기

- 작업 범위의 화면과 상태를 목록으로 만들고 각 항목에 기준 링크 또는 파일을 연결한다.
- 문구와 구조, 실제 표시되는 값, 상태 전환을 확인한다. 정지 자료에 빠진 동작은 연결된 프로토타입·명세·기존 구현에서 확인한다.
- 문구는 가능한 경우 추출해서 비교한다. 치수와 색은 대상 폭·모드에서 확인하고 데모 데이터와 실제 표시 규칙을 구분한다.
- 플랫폼 고유의 글꼴 렌더, 안전영역, 스크롤과 동적 콘텐츠는 실제 실행 환경에서 확인한다.
- 자료가 충돌하거나 빠져 있으면 [화면별 기준 판정](source-precedence.md)을 적용한다.
