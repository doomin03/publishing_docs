# 플랫폼: 웹

Vue의 SCSS 구조를 설정하거나 화면 폭에 따른 배치·탐색을 변경할 때는 [Vue SCSS 구조와 반응형·적응형 구현](vue-layout.md)을 적용한다.

1. 라우터와 실행 스크립트에서 대상 앱과 진입 경로를 찾는다. 공통 레이아웃·컴포넌트·테마·토큰·UI 라이브러리 적용 지점을 확인한다.
2. 디자인 프레임이나 목업의 기준 폭을 기록하고 프로젝트의 반응형 중단점과 대응시킨다. 여러 레이아웃이 있으면 각 기준 폭과 중단점 주변을 검증한다.
3. 실제 브라우저에서 폰트 로드, 줄바꿈, 오버플로, 스크롤 영역, 고정 요소와 키보드 포커스를 확인한다.
4. 저장소에 시각 회귀 도구가 있으면 기존 브라우저·뷰포트·기준선 설정을 사용한다. 도구가 없으면 변경 상태를 렌더링해 입력 자료와 대조하고 확인 환경을 기록한다.
